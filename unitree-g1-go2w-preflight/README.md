# 宇树 G1、Go2W 二次开发与上机前预检

面向宇树 G1、Go2W 的机器人操作系统、软件开发工具包集成，以及安防巡检、移动操作和现场交付前的只读预检。

本目录由独立开发团队维护，不属于宇树官方产品或官方认证。默认不发送运动、电机、机械臂、夹爪、模式切换或生产系统写入命令。

## 可协助的工程方向

- G1、Go2W 网络、固件、模式、控制权和状态新鲜度检查；
- 机器人操作系统与软件开发工具包的通信配置、接口适配和问题定位；
- 安防场景自主导航、地图、定位、避障、停止与异常恢复；
- G1 加装机械臂后的抓取、按钮、开关门和受约束维修任务拆分；
- 巡检平台、告警、工单和业务系统接口对接；
- 现场勘察、试点范围冻结、试运行记录、培训与验收资料整理。

开发团队已有安防自主导航演示，并可进行机械臂集成与抓取、维修、开关门等任务开发；具体型号、负载、精度、现场稳定性和验收状态必须按项目配置重新确认，演示不等于量产、认证或客户验收。

## 工程证据边界

- 网络连通不代表机器人状态新鲜；
- 接口调用成功不代表物理动作完成；
- 仿真通过不代表真机通过；
- 静止抓取成功不代表移动抓取稳定；
- 单次演示不代表连续运行、无人值守或生产验收；
- 浏览、下载、提交表单或展示收款码均不代表已付款。

任何真机动作都需要单独明确授权、现场许可、清场、观察人员、人工接管和独立停止条件。
