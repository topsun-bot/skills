# Visual direction

## Default look: illustrated field notebook

Use this when the user admires hand-drawn, editorial, premium, exploratory presentation pages but has not supplied a brand system.

- Base: warm off-white paper, faint grain, imperfect ink lines, generous margins.
- Ink: charcoal rather than pure black.
- Accents: muted teal for structure, restrained coral for action, ochre for sequencing.
- Imagery: scientific sketch, editorial collage, annotated mechanism, cut-paper or watercolor wash.
- Composition: one dominant visual field with a deliberate quiet zone for live HTML text.
- Framing: thin rules, registration marks, page numbers, subtle stacked-paper depth.
- Motion: 180–420 ms fades, masks, and small translations. Avoid constant floating or parallax.
- Type: system serif for editorial emphasis and system sans-serif for controls. Avoid remote font dependencies unless approved.

Do not reproduce a reference's logo, exact page arrangement, distinctive illustrations, or branded wording. Translate the qualities into an original system.

## Image-generation brief

Generate one illustration at a time. Keep the prompt explicit about:

1. the page's single claim;
2. the required objects and their relationship;
3. hand-drawn medium and restrained palette;
4. 16:9 or 3:2 composition;
5. quiet zone matching the HTML text layout;
6. no embedded words, labels, UI, logo, watermark, or frame;
7. literal visual accuracy requirements;
8. consistent art direction shared by the deck.

Example prompt skeleton:

> Editorial scientific field-notebook illustration explaining [claim]. Show [objects] arranged so [relationship] is visually obvious. Fine charcoal ink, light watercolor wash, warm archival paper, muted teal and restrained coral accents, premium museum-catalog composition. Wide 16:9 scene with a quiet low-detail area on the [left/right] for HTML text. No words, letters, numbers, captions, logo, watermark, UI, or border.

Inspect every generated image. Reject illegible anatomy, contradictory geometry, accidental text, fake evidence, and inconsistent palette. Generated illustration may explain a concept; it must not be presented as a documentary photograph or source figure.

## Choosing a visual form

- Use a **hero scene** for a hook or future state.
- Use a **before/after split** for change.
- Use a **three-beat strip** for a process.
- Use an **exploded diagram** for a mechanism.
- Use a **map or branching tree** for relationships.
- Use a **specimen board** for categories.
- Use a **single dark field** for a risk, constraint, or decisive conclusion.
- Use a **decision canvas** for questions requiring audience participation.

Keep explanatory text in HTML so it remains selectable, accessible, correctable, and crisp when projected.
